# Question Answering with BERT

This project implements a simple question answering system using TensorFlow Hub and a fine-tuned BERT model.

## Files

- `0-qa.py` - Finds an answer to a question from a reference document.
- `1-loop.py` - Basic interactive question loop.
- `2-qa.py` - Interactive question answering using a single reference document.
- `3-semantic_search.py` - Performs semantic search over a corpus using the Universal Sentence Encoder.
- `4-qa.py` - Interactive question answering over multiple documents using semantic search and BERT.

## Requirements

- Python 3
- TensorFlow
- TensorFlow Hub
- transformers
- NumPy
